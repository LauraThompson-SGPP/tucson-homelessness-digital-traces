# Results Directory

This directory holds analysis outputs generated by the scripts in `Code/`.

| File | Created by | Contents |
|------|-----------|----------|
| `data_summary.csv` | `02_clean_data.R` | Sample sizes, date range, author counts |
| `sentiment_summary.csv` | `03_sentiment_analysis.R` | Overall sentiment means and proportions |
| `sentiment_posts_monthly.csv` | `03_sentiment_analysis.R` | Monthly sentiment for posts |
| `sentiment_comments_monthly.csv` | `03_sentiment_analysis.R` | Monthly sentiment for comments |
| `topic_top_terms.csv` | `04_topic_modeling.R` | Top FREX, probability, and lift terms per topic |
| `topic_prevalence.csv` | `04_topic_modeling.R` | Overall topic prevalence (share of corpus) |
| `fig_volume.png` | `05_visualizations.R` | Monthly post/comment volume |
| `fig_sentiment_trend.png` | `05_visualizations.R` | Mean monthly sentiment, posts vs. comments |
| `fig_topic_prevalence.png` | `05_visualizations.R` | Topic prevalence bar chart with top terms |
| `fig_wordcloud.png` | `05_visualizations.R` | Word cloud of top comment terms |

Outputs may be committed to GitHub since they contain only aggregated /
non-identifiable information.
